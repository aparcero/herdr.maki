## Review

The diff adds an ast-grep adapter, a zai-local provider, a Python/Maki integration suite, and manifest/doc updates. I validated it against the real toolchain rather than just reading it: `just check` (22/22 tests pass against real Maki 0.7.2 + ast-grep 0.51.1), direct ast-grep CLI probes for every output contract the adapter depends on, Maki's official package/permissions/Lua-API docs for every manifest key and API used, and an empirical loopback check of the built-in `zai` provider's wire behavior.

Findings:

1. **minor** `lua/ast_grep/init.lua:201-207`: An apply that finds zero new matches is reported as a failure with a false "may have changed some files" warning. If files change between the preflight preview and the `--update-all` run (external formatter/build/git checkout — serialization only covers this one Maki instance), ast-grep exits 1 with empty output, so the `exit_code ~= 0` branch fires and `operation.applying` appends the PARTIAL warning, even though nothing was written. Fail-closed and self-correcting on retry, but the message misdirects the user/model toward diff inspection for a no-op; checking exit 1 + empty report as "nothing to apply" (or routing it through the `Applied N changes` check) would be accurate. No test covers "preview N>0 → apply 0 matches" (mocked cases all use exit≠0 or a report line).

Everything else held up under scrutiny:

- ast-grep contracts verified on the real binary: `--json=compact` array shape incl. `replacement`; exit codes (0/1 no-match/2 bad language or path/8 pattern error); `Applied N changes` is always plural (N=1 and identity rewrites included), so the strict `^Applied %d+ changes$` check is safe; missing paths produce stderr + exit 1, which the stderr-must-be-empty check correctly turns into an error before any write; `--debug-query` + `--stdin` prints the tree to stderr without walking the cwd (multi-statement `pattern` format fails with `Error:` first, matching the code's `^Debug ` gate, while `ast`/`cst` show the tree then the note — exactly what the docs and tests claim).
